靜電相吸排斥定則

「同性相斥，異性相吸」。

• 陰離子帶負電 (－)，受正電極吸引向正極 (陽極) 漂移。
• 陽離子帶正電 (＋)，受負電極吸引向負極 (陰極) 漂移。

潤濕劑 KNO₃ (硝酸鉀) 的角色

提供自由移動之解離離子 (K⁺ 與 NO₃⁻)，使乾濾紙轉變為導電解質通道，以利通電完成電路迴路。

• 無色無干擾：K⁺ 與 NO₃⁻ 皆為無色，不遮蓋樣品色帶痕跡。
